Recitation Session

Set the surah/ayah (and an optional type code + note — see legend below) before tapping "➕ Mistake" to log exactly where each mistake happened — powers "Ayat You Mistake Most" in Logs. Leave the ayah blank to just tally the count. Every tap (and any manual edit to Mistakes) saves immediately — switching Hizb starts a fresh session.

Import Mistakes

Also accepts "r15-23x20" (range) or "r15x30" (single ayah) for Practice More drill goals — add "done", "d", or "✅" right after the count (e.g. "r15-23x20 done") to log it as already-completed; "p15x20 done" works the same for pages. Use "//" on its own line to close the surah context so the next message needs an explicit "3:" surah. Combining "A" with another code marks a near-miss, e.g. "218 AB". This adds to what's already logged — it won't remove anything.

Import from Telegram

Fetches new messages from the Telegram channel and adds anything not already logged — same format as "Import Mistakes" in Log a Session. Asks for a surah if a message doesn't specify one; always safe to re-run.
The button above only ever sees Telegram's own ~20 most recent messages at a time — for a full catch-up (a long gap since your last import, or the very first time), export the channel's entire history instead: on Telegram Desktop, open the channel → ⋮ menu → "Export chat history" → JSON format, then pick the resulting result.json here. Goes through the exact same parsing and dedup as a live import — nothing is ever duplicated, whichever way a message was first imported.
Post a message containing just "start" (or 🚩) on the channel to mark a checkpoint — both import buttons above will then skip that message and everything before it, in every future run, until you clear the checkpoint or check the box above for a one-off import of everything. Posting a newer "start"/"🚩" message later moves the checkpoint forward automatically.

Verify Telegram Import

Every Telegram-imported mistake, grouped by the message it came from, newest message first — read this top to bottom the same way you'd scroll the Telegram channel from the bottom up, to quickly confirm everything made it in correctly.

Auto-save to Local File

Link a .json file once — it's silently overwritten on every mistake, session, or practice-range save. No browser prompt after the first link. Works offline. Not a replacement for Firebase sync — just a second copy on this device.

Save / Load Backup

The saved file is JSON you can edit directly (change a value, delete an entry, copy one to add a new one). It also includes the Tracker page's memorized surahs, so one file backs up both apps. Importing REPLACES everything currently saved with exactly what's in the file — you'll get a confirmation showing the counts before anything changes. You can also post this file to your Telegram channel as a backup — both import buttons above will silently skip it (file attachments with no caption are never treated as log data).
