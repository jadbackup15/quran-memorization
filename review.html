Recitation Session

Set the surah/ayah (and an optional type code + note — see legend below) before tapping "➕ Mistake" to log exactly where each mistake happened — powers "Ayat You Mistake Most" in Review & Analyze. Leave the ayah blank to just tally the count. Every tap (and any manual edit to Mistakes) saves immediately — switching Hizb starts a fresh session.

Import Mistakes

Pick the starting surah, then paste one ayah number per line — an optional type code (S/B/W/M/T/A) and note can follow, with or without a space, e.g. "255S", "255 S", or "218 B forgot ina". Combine codes for an ayah with more than one mistake, e.g. "255SB" (both S and B). "A" (Needs Attention) isn't a mistake, so it's tracked separately in Review & Analyze and doesn't add to any mistake count (and can't combine with other codes). Any line that doesn't start with a number (like a title) is ignored. To switch surah mid-paste (e.g. a Hizb like Hizb 5, ending Al-Baqara and starting Aal-i-Imran, in one go) put "3:" on its own line — every bare ayah number after it belongs to that surah until the next "N:" line — or "3:15" to switch AND log ayah 15 as a mistake in one line. A Hizb touched more than once (whether by a surah switch, a separate paste, or a live session) merges into that Hizb's existing session for today rather than splitting into two. This ADDS to what's already logged; it won't remove anything.

Import from Telegram

Fetches messages from the Telegram channel and adds any ayah mistakes from them that aren't already logged here — same one-ayah-per-line format as "Import Mistakes" in Log a Session (including "3:" / "3:15" to switch surah), using the surah picked here as the default for any message that doesn't switch surah itself. Safe to re-run any time: a mistake already logged from a given message is never duplicated, but if you delete a mistake that came from Telegram, running this again brings it back — nothing here is "done forever", only "still present or not". Telegram's own notices ("Channel created", "X pinned...") and any message that doesn't look like log data (no line starting with a number) are skipped automatically.

Save / Load Backup

The saved file is JSON you can edit directly (change a value, delete an entry, copy one to add a new one). It also includes the Tracker page's memorized surahs, so one file backs up both apps. Importing REPLACES everything currently saved with exactly what's in the file — you'll get a confirmation showing the counts before anything changes.

🔍 Mutashabihat Finder

Pick one ayah and a surah to search — returns every ayah in that surah whose wording closely resembles it, ranked most-similar first, so you can find (and save) the real match instead of guessing.
Pick a range — every pair of ayat within it whose wording closely resembles each other is returned, ranked most-similar first. Capped at 400 ayat total (about a Hizb) since every ayah is compared against every other one — narrow the range if it's rejected.

Add a Mutashabihat Group

Start with just one ayah (from any surah) you find easy to mix up, or add more now if you already know what it's confused with — either way, use "✎ Edit" on the saved group below to add the rest whenever you figure it out. Groups are ranked by how many mistakes you've logged on any of their ayat — via the ➕ Mistake tap in Hizb Log — so the ones you actually confuse most in practice rise to the top.
