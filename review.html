Ayat You Mistake Most

Pick the surah, then paste one ayah number per line — an optional type code (S/B/W/M/A) and note can follow, e.g. "255 S" or "218 B forgot ina". "A" (Needs Attention) isn't a mistake, so it's tracked separately below and doesn't add to any mistake count. Any line that doesn't start with a number (like a title) is ignored. Also adds one Recitation Log session per Hizb the pasted ayat fall in (skipping Hizb where every pasted ayah was "A"). This ADDS to what's already logged; it won't remove anything.

Recitation Log

The saved file is JSON you can edit directly (change a value, delete an entry, copy one to add a new one). It also includes the Tracker page's memorized surahs, so one file backs up both apps. Importing REPLACES everything currently saved with exactly what's in the file — you'll get a confirmation showing the counts before anything changes.

Add a Mutashabihat Group

Add two or more ayat (from any surah, not just pairs) that you find easy to mix up. Groups are ranked by how many mistakes you've logged on any of their ayat — via the ➕ Mistake tap in Hizb Log — so the ones you actually confuse most in practice rise to the top.
